# Capstone — Predictive Sensor Node

Start with `make ready`. Combine the accepted outputs from Labs 1–4 without changing their hashes. Use `make evidence`, then `make package` to create the manifest-bound archive described on the course capstone page.

Expected result: the archive identifies one course/starter version, dataset, scaler, model, firmware, vector suite, and UART log. Add the engineering report that explains resource tradeoffs, bounded failure behavior, and the claims that still require optional physical hardware.

If packaging reports a missing or mismatched artifact, repair the named evidence at its originating lab. Do not edit digests manually or select a different file merely to satisfy the manifest.
